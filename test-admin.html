🧪 Test Admin Functions

Nếu bạn chưa có tài khoản admin, hãy tạo một tài khoản test với role: 'admin' trong database.

Test Data Setup:

// Tạo tài khoản admin test
const adminUser = {
    id: 999,
    name: 'Admin User',
    email: 'admin@test.com',
    password: '123456',
    role: 'admin',
    phone: '0123456789',
    address: 'Admin Address',
    created_at: new Date().toISOString()
};

// Thêm vào database.users
database.users.push(adminUser);
localStorage.setItem('database', JSON.stringify(database));
